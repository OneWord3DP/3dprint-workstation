📰 Fabbaloo · 本周设计
Fabbaloo 本周设计：已灭绝独岛海狮骨架 3D 打印复原
2026-10-26
Fabbaloo 本周设计选了韩国海洋水产部与国立海洋生物多样性研究所的复原项目：用 3D 扫描与打印重建已灭绝的独岛海狮骨架，41 根骨头打印组装后展出，让参观者直观感受到灭绝的含义。
  • 41 根骨头全部打印并组装：以现存骨骼样本 3D 扫描建模，缺失部位参照结构相近的加州海狮补齐
  • 现于首尔站展出，之后将移交国立海洋生物多样性研究所继续展览
  • 独岛海狮（日本海狮）因 20 世纪初的商业捕猎而灭绝，1970 年被宣布灭绝
📰 SFF Geek · 配件上新
Prusa OpenPrintTag 升级 10 月 26 日发货，售价 19.44 美元
2026-10-25
Prusa 的 OpenPrintTag 升级终于发货：给 CORE One 系列装上 NFC 读头，料盘标签里的材料、颜色与剩余量可直接被打印机读取，迟到了约七个月——原定 2026 年第一季度推出，此前只能靠手机 App 使用标签。
  • 售价 19.44 美元，10 月 26 日开始发货；装于 CORE One 料盘架、接 xBuddy 板 CAN 口
  • 放入带标签的料盘即读材料与颜色、自动加热；打印结束把剩余料量写回标签，全程可离线
  • 支持 CORE One / CORE One+ / CORE One+（Gen 2）/ CORE One L / CORE One L+；暂不支持 INDX、MMU3、MK4、XL 与 MINI
  • 黑五期间购买 CORE One+（Gen 2）或 CORE One L+ 可免费获赠该升级
📰 How-To Geek · 实用玩法
6 个让家更有“定制感”的 3D 打印项目
2026-10-25
How-To Geek 整理了 6 个让家里更有“定制感”的打印项目：核心思路不是打摆件，而是把打印件做进家里——藏线、柔光、藏传感器、省空间的厨房收纳与模块化整理，都是即打即用的家居改造。
  • 藏线与理线：桌下走线、穿墙线管与参数化线环，让线材不再铺满地面
  • 透明耗材打印 LED 灯带柔光罩，散射光线、弱化单颗灯珠
  • 智能家居支架：传感器、音箱与 ESP32 微控制器都可用打印件藏进墙面或家具
  • 厨房与收纳：锅盖架、砧板架、杯架与 Gridfinity / Multiboard 模块化收纳
📰 3dprinting.com · 实用玩法
免费插件 print3d：让 AI Agent 照着照片建模、直出拓竹打印
2026-10-24
维罗纳开发者 Marco Franzon 的免费插件 print3d 被称为“实物版 REA”：让 AI Agent 照着照片、想法或商品链接反向建模，再直出拓竹打印——“看到什么就能打什么，不需要建模技能”，但目前只针对拓竹 X2D，且插件进 Hermes 官方目录的申请仍在等待。
  • 不是文字生成 3D：Agent 写 Blender 脚本建模，插件校验网格、用 Bambu Studio 命令行切片，失败自动重跑
  • 照片是输入：正对拍摄、旁边放银行卡或硬币作尺寸参照，再把模型轮廓叠回照片做相似度校验
  • 实测：奥克兰博物馆木衣夹照片建模，长度 114.9 毫米（馆藏数据 115 毫米），覆盖照片轮廓 90%
  • 目标机型为拓竹双喷头 X2D；10 月 21 日演示已用照片生成两件式树莓派外壳
